### Question-Aware Answer Structuring

A Python pipeline that transforms OCR-extracted student answers into question-aware JSON. The system combines deterministic segmentation with a local LLM for genuinely ambiguous cases and preserves uncertain content for review instead of guessing.

  <code>Python</code>
